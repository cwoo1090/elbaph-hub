## Loki — 08:46
네, **Claude Code(클로드 코드)**는 슬랙(Slack)과 통합하여 사용할 수 있습니다. Anthropic은 2025년 말부터 클로드의 '에이전트' 기능을 슬랙 내에서 바로 사용할 수 있는 기능을 베타(Research Preview)로 제공하고 있습니다.

원하시는 **"새 대화 시작 = 새 쓰레드"** 느낌의 워크플로우로 충분히 활용 가능합니다.

**1. 주요 특징 및 작동 방식**
• **쓰레드 기반 컨텍스트 이해:** 슬랙 채널에서 특정 버그 리포트나 기능 요청이 오갔을 때, 해당 쓰레드에서 `@Claude`를 태그하면 쓰레드 내 대화 내용을 맥락으로 파악하여 코딩 작업을 시작합니다.
• **자동 라우팅:** 사용자가 `@Claude`를 부르면 클로드가 의도를 분석합니다. 코딩 작업임이 확인되면 자동으로 **Claude Code** 세션을 시작합니다.
• **비동기 업데이트:** 클로드가 코드를 수정하거나 테스트를 돌리는 동안 진행 상황을 슬랙 쓰레드에 실시간으로 업데이트해 줍니다.
• **PR 생성 및 결과 보고:** 작업이 완료되면 요약 보고서와 함께 GitHub/GitLab의 Pull Request 링크를 쓰레드에 바로 남겨줍니다.

**2. 사용 방법 (설정 조건)**
• **준비물:** Claude Pro, Team 또는 Enterprise 플랜 계정이 필요합니다.
• **설치:** 슬랙 앱 디렉토리에서 **'Claude'** 앱을 설치하고 본인의 Anthropic 계정을 연동해야 합니다.
• **실행:** 채널이나 DM에서 `@Claude`를 멘션하고 "이 버그 좀 수정해줘" 또는 "이 기능 구현해서 PR 올려줘"라고 요청하면 됩니다.

**3. '새 대화 = 새 쓰레드' 활용 팁**
• **주제별 분리:** 특정 이슈마다 새 쓰레드를 만들어 논의하고 그 안에서 클로드를 호출하면, 클로드가 다른 쓰레드의 잡음 없이 해당 이슈에만 집중하게 할 수 있습니다.
• **DM 활용:** 혼자 조용히 코딩 비서로 쓰고 싶다면 클로드 앱과의 1:1 DM을 사용하면 됩니다. DM 내에서도 개별 메시지에 쓰레드를 만들어 단일 작업 단위로 관리하기 좋습니다.

**4. 기타 도구 (MCP Bridge)**
공식 통합 외에도 **MCP(Model Context Protocol)**를 이용한 커뮤니티 브릿지(예: Slack-Claude Bridge)를 사용하면 터미널의 Claude Code CLI를 슬랙과 직접 연결하여 더 강력한 제어권을 가질 수도 있습니다.

현재 빌더 커뮤니티(ELBAPH)에서 협업 도구로 슬랙을 쓰신다면, 개발 논의가 일어나는 바로 그 자리에서 코드를 짜게 시킬 수 있어 생산성 향상에 매우 효과적입니다.

## Loki — 08:49
네, 가능합니다! 클로드가 슬랙 전체의 대화 기록을 마치 **코드베이스를 검색하듯 훑어서 답변하고, 그 내용을 대화 컨텍스트에 포함**시키는 기능이 존재합니다.

크게 두 가지 방식(공식 커넥터, MCP)으로 구현할 수 있습니다.

**1. Claude 공식 슬랙 커넥터 (Slack Connector)**
Anthropic은 [Claude.ai](http://Claude.ai)(웹/데스크톱 앱)에서 슬랙 데이터를 직접 불러올 수 있는 **'커넥터'** 기능을 제공합니다.
• **작동 방식:** 클로드 웹 설정에서 슬랙을 연동하면, 클로드가 도구(Tools)를 사용해 슬랙의 채널, DM, 공유된 파일을 **직접 검색(Search)**합니다.
• **활용 예시:** "지난달 #dev-robotics 채널에서 BCI 센서 노이즈 이슈에 대해 결정된 사항이 뭐야?"라고 물으면, 클로드가 해당 시점의 대화를 찾아 요약해줍니다.
• **조건:** Claude **Team** 또는 **Enterprise** 플랜 사용자여야 하며, 관리자가 커넥터를 활성화해야 합니다.

**2. MCP(Model Context Protocol) 기반 연동**
최근 출시된 MCP를 이용하면 훨씬 강력한 '전체 훑기'가 가능합니다.
• **작동 방식:** `Slack MCP Server`를 설치하면, 클로드(특히 Claude Code CLI나 데스크톱 앱)가 슬랙 API를 통해 특정 채널의 히스토리 전체를 읽거나 검색할 수 있는 권한을 가집니다.
• **장점:** 공식 커넥터보다 더 세밀한 제어가 가능합니다. 특정 쓰레드 전체를 긁어오거나, 특정 기간의 대화 로그를 텍스트 파일처럼 인식시켜 분석하게 할 수 있습니다.

**3. 슬랙 앱 내에서의 '맥락 파악' 범위**
슬랙 앱(`@Claude` 호출)을 직접 사용할 때 클로드가 읽는 범위는 다음과 같이 정해져 있습니다:
• **채널 멘션:** 호출된 시점의 **최근 메시지 약 20개**.
• **쓰레드 답변:** 해당 쓰레드의 **최근 메시지 약 50개**.
• **메시지 전달(Forwarding):** 특정 메시지를 클로드 앱으로 전달하면 **최대 100개**의 맥락을 읽습니다.

**요약: "슬랙을 코드베이스처럼 쓰려면?"**
단순히 채널에서 `@Claude`를 부르는 것보다, **[Claude.ai](http://Claude.ai) 웹에서 '슬랙 커넥터'를 연결**하거나 **Claude Code에 Slack MCP를 연결**하는 것이 질문하신 목적(전체 훑기 및 컨텍스트 포함)에 가장 부합합니다.

이렇게 하면 "예전에 누가 슬랙에 올렸던 코드 스니펫 찾아줘" 같은 요청도 코드 수정 작업의 일부로 자연스럽게 처리할 수 있습니다. 건승을 빕니다, 빌더님! :mechanical_arm:
