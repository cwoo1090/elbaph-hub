밋업 발표를 글로 남기는 flow

현재 블로그 제작 flow

1밋업 세션 녹음
2ClovaNote STT로 transcript 생성
3발표자료 + transcript + prompt를 LLM에 입력
4발표자에게 공유 후 최종 편집
5사이트 업로드, 이후 newsletter로 재활용

발표자료를 올려줘야 블로그 초안 품질이 올라갑니다. 정리된 글은 이후 newsletter 콘텐츠로 다시 씁니다.
