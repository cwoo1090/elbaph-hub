# Topic Research

When invoked with a topic:

1. Read [reference.md](reference.md) for research guidelines and format
2. Web search the topic from multiple angles (recent news, papers, key players, trends)
3. Synthesize findings into a structured report
4. Post the report to #lounge channel (`C0AA15Q77FS`) via Slack MCP
5. Save the report to `archive/YYYY-MM-DD-[topic-slug].md`

If no topic is provided, ask the user what they want researched.
