# Research Reference

## Guidelines

- Search from multiple angles: recent news, academic papers, key companies/people, market trends
- Prioritize recent information (last 1-3 months)
- Include both global and Korea-specific perspectives where relevant
- Aim for 5-10 key findings per report
- Be objective — present facts, not hype

## Slack Message Format

```
🔬 *Elbaph Research — [Topic]*

---

*📌 TL;DR*
[2-3 sentence summary of the most important takeaways]

*Key Findings:*

*1. [Finding title]*
[2-3 sentence explanation]

*2. [Finding title]*
[2-3 sentence explanation]

...

*🔗 Why This Matters for Elbaph*
[1-2 sentences connecting this to members' interests]

---
_Researched by Elbaph Bot 🤖_
```

## Archive Format

Save to `archive/YYYY-MM-DD-[topic-slug].md`:

```markdown
# Research — [Topic]
Date: YYYY-MM-DD

[same content as Slack message, in plain markdown]
```
