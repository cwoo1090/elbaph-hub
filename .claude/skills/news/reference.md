## Formatting Rules

- Bold the company/product name, then a concise one-line summary
- Skip a topic section if no meaningful news that day
- No links in the Slack message — keep it clean and scannable
- Write in English

## Archive Format

Save to `archive/YYYY-MM-DD.md` with the same content as the Slack message, plus a header:

```markdown
# Daily Briefing — YYYY-MM-DD

[same content as Slack message, in plain markdown]
```
