# Meetup Reference

## Schedule

- Frequency: Monthly (one Saturday or Sunday)
- Time: ~10am
- Format: Each member prepares a 15-min topic to share
- New members: Admitted by unanimous consent (1-4 voting among existing members)

## Reminder Timeline

| When | Action | Channel |
|------|--------|---------|
| 2 weeks before | Topic submission call | #meetups |
| 1 day before | Final reminder (time, location, topics) | #meetups |

## Message Formats

### Topic Call (2 weeks before)

```
📋 *Elbaph Meetup — Topic Submission*

다음 모임이 [date]에 예정되어 있습니다!
각자 15분 발표 주제를 이번 주까지 이 채널에 공유해주세요.

주제는 자유입니다 — 최근 관심사, 진행 중인 프로젝트, 읽은 논문/책 등 뭐든 좋습니다.
```

### Final Reminder (1 day before)

```
🔔 *Elbaph Meetup — Tomorrow!*

📅 [date], [time]
📍 [location]

*Topics:*
• [Member] — [topic]
...

내일 봐요! 🙌
```

## Archive Format

Save to `archive/YYYY-MM-DD.md`:

```markdown
# Meetup Reminder — YYYY-MM-DD

Type: [topic-call / final-reminder / custom]

[message content]
```
