# Elbaph Site

Next.js 15 public site for Elbaph — bilingual (ko/en), deployed on Vercel.

## Dev

```bash
npm run dev   # http://localhost:3001
```

Deploy manually: `npx vercel --prod --yes`

## Design Context

### Users
Prospective members and guest speakers — ambitious, technically sophisticated builders, mostly Korean, bilingual. They're evaluating "Is this crew worth my time?" The site answers that with credibility, not persuasion.

### Brand Personality
**Ambitious · Intellectual · Bold**

Direct, no-filler, high-standards. What the crew has built speaks for itself. Korean warmth and camaraderie coexist with intense drive.

### Aesthetic Direction
- **Theme**: Light mode — warm off-white `#faf9f6`, not pure white
- **References**: YC/Pioneer energy (selectivity, credibility) + Linear/Vercel execution (typographic precision, restraint)
- **Anti-references**: No gradient heroes, no floating cards, no stock photos, no purple/blue brand colors, no SaaS landing page clichés
- **Pattern**: Editorial grid — `gap-px border` cells, high contrast text, generous whitespace

### Design Principles
1. **Credibility over persuasion** — Show the people, the work, the ideas
2. **Every pixel earns its place** — No decorative elements without meaning; restraint signals confidence
3. **Typographic hierarchy does the work** — Bold display headlines, muted labels, clear body; no icons or illustrations
4. **Korean-first, English-equal** — Both locales must feel native; accommodate Korean character density
5. **Bold but not loud** — Ambition lives in ideas and people, not visual effects; motion and color are purposeful and rare
